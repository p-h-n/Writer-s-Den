[LOG #1. 20/10/2026.]

This is the first entry in the documentation of my personalised writing tool, which I call the Writer’s Den. I have not yet been able to update the code, but I have left comments in it to keep me on track and to indicate what I should build next.

At the time of writing, I have a working JFrame with a functional menu. However, two of its options, New Project and Load Project, are currently programmed to do nothing. The Exit button is the only one that works.

My next step is to make the New Project and Load Project buttons perform their intended functions. This will involve a significant amount of file handling, as the project is currently designed to work with basic text files and folders, with the sole exception of an .odt file.

Once those functions are working, the greater challenge may be getting the application to look exactly the way I want. One of my goals for the interface is to draw inspiration from Obsidian’s UI, particularly for the notes and outline sections. I believe this would make the application more visually appealing, but I will decide how to implement it when I reach that stage.
